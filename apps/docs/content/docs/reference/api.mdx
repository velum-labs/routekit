# API reference

Symbol-level API docs are generated with TypeDoc. They are **not** committed;
run generation when you need them:

```sh
pnpm docs:generate-code
```

Output lands in `apps/docs/generated/api/` (gitignored). Browse the package
`README.md` files there, or open this docs site after generation for narrative
guides and the [package map](/docs/reference/packages).
