# Commands

## Lifecycle

```sh
routekit start
routekit status
routekit stop
```

## Accounts and providers

```sh
routekit accounts login claude-code --name personal
routekit accounts login codex --name work
routekit accounts rename codex work personal
routekit accounts status
routekit providers add openai
routekit models list
```

## Remote gateways

```sh
routekit remote add <name> --url <gateway> --ssh <host>
routekit remote install <name>
routekit remote list
routekit remote show <name>
routekit remote use <name>
routekit remote remove <name>
```

Target overrides: `--remote <name>` and `--local`.

## Coding tools

```sh
routekit codex
routekit claude
routekit cursor
```

## Usage and quotas

```sh
routekit usage
routekit usage --watch 10
routekit usage redeem --provider codex
routekit usage redeem --provider codex --label work --credit-id RateLimitResetCredit_… --yes
```

`usage redeem` interactively selects an eligible account and reset credit when
they are omitted. Non-input use requires `--yes`; without an explicit ID it
chooses the soonest-expiring detailed credit, or lets the provider choose when
only an aggregate count is available.

## Usage leaderboard

```sh
routekit leaderboard
routekit leaderboard --by model --sort requests
routekit leaderboard --window 24h --json
```

Ranks named principals (default), models, or providers over retained call
attribution. With durable rollups enabled, the command defaults to the longest
supported retained window (`7d` for retention of at least seven days, otherwise
`24h`). Without durable rollups it defaults to `live`. Historical windows
require `leaderboard.durable: true` in `router.yaml`.
