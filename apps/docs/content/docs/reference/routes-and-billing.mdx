# Routes and billing

This page is the public RouteKit launch-support disclosure. The maintainer
mirror lives at
[`docs/routekit-routes-and-billing.md`](https://github.com/velum-labs/routekit/blob/main/docs/routekit-routes-and-billing.md).

All seven routes remain **Planned Supported until L06 closes**. The canonical
durable report currently marks every route `pending`. Its evidence baseline is
RouteKit 0.8.0 revision
[`be81fa847d74c64fa8720c9ecf1d0c6abebd58fa`](https://github.com/velum-labs/routekit/commit/be81fa847d74c64fa8720c9ecf1d0c6abebd58fa)
(2026-07-22) and the corresponding
[end-to-end matrix](https://github.com/velum-labs/routekit/blob/be81fa847d74c64fa8720c9ecf1d0c6abebd58fa/docs/routekit-e2e-matrix.md).
Deterministic case passes do not promote a route while required live or manual
outcomes remain pending.

## Shared contract

- A requested namespaced model never falls through to another provider.
- API routes have no RouteKit account-pool or cross-provider failover.
- Subscription pools rotate only among eligible accounts of the same kind.
- RouteKit makes no unlimited-use claim. Provider terms and quotas always apply.
- Portable message and tool history can cross compatible routes. Opaque
  encrypted reasoning is retained only for its originating provider and native
  model.

Inspect a live route with:

```sh
routekit models info <provider/model>
```

The response includes namespaced and native model IDs, provider, account class,
billing mode (`api-key` / `metered-api`, `subscription` / `subscription`), and
capabilities. Unknown models fail. Credentials are never returned. See also
[route explanation evidence](https://github.com/velum-labs/routekit/blob/main/docs/routekit-route-info-evidence.md).

<a id="route-openai-api"></a>

## OpenAI API

- **Status and evidence:** Current qualification: pending. The RouteKit 0.8.0 /
  2026-07-22 durable report records a deterministic pass while required live
  protocol, billing, and failure outcomes remain pending.
  [Evidence](https://github.com/velum-labs/routekit/blob/main/docs/routekit-l06-evidence.md#route-openai-api).
- **Credential:** User-owned `OPENAI_API_KEY`; optional `OPENAI_BASE_URL`.
- **Billing:** Metered API-key route; OpenAI determines charges.
- **Egress and aggregator:** Direct to `api.openai.com` unless overridden. No
  aggregator.
- **Quota and failover:** Provider errors return to the caller; no account pool
  and no silent cross-provider fallback.
- **Protocol and limitations:** OpenAI Chat Completions and native Responses.
  Direct OpenAI API routes keep `/v1/responses` requests on the native Responses
  endpoint, preserving tools, reasoning, streaming, continuation IDs, and opaque
  response items without translating through Chat Completions.
- **Unlimited use:** RouteKit makes no unlimited-use claim.

<a id="route-anthropic-api"></a>

## Anthropic API

- **Status and evidence:** Current qualification: pending. The RouteKit 0.8.0 /
  2026-07-22 durable report records a deterministic Messages pass while
  required live protocol, billing, and failure outcomes remain pending.
  [Evidence](https://github.com/velum-labs/routekit/blob/main/docs/routekit-l06-evidence.md#route-anthropic-api).
- **Credential:** User-owned `ANTHROPIC_API_KEY`; optional `ANTHROPIC_BASE_URL`.
  RouteKit does not currently use `ANTHROPIC_AUTH_TOKEN` for provider requests.
- **Billing:** Metered API-key route; Anthropic determines charges.
- **Egress and aggregator:** Direct to `api.anthropic.com` by default. No
  aggregator.
- **Quota and failover:** Provider errors return to the caller; no account pool.
- **Protocol and limitations:** Native Messages with streaming, tools, and
  thinking where supported.
- **Unlimited use:** RouteKit makes no unlimited-use claim.

<a id="route-bedrock-api"></a>

## Amazon Bedrock

- **Status and evidence:** Current qualification: pending. Authorized-operator
  protocol, billing, failure, and live model evidence remains pending in the
  RouteKit 0.8.0 / 2026-07-22 durable report.
  [Evidence](https://github.com/velum-labs/routekit/blob/main/docs/routekit-l06-evidence.md#route-bedrock-api).
- **Credential:** Operator-owned AWS SDK default-chain identity and region; see
  the [AWS Bedrock guide](/docs/guides/aws-bedrock).
- **Billing:** Direct AWS Bedrock Runtime route; AWS determines charges and
  credits are account-specific.
- **Egress and aggregator:** Direct to AWS Bedrock in the configured account and
  region. No aggregator, though cross-region inference profiles can route to AWS
  destination regions.
- **Quota and failover:** AWS model access, IAM, service quotas, and throttling
  apply. Provider errors return to the caller; no silent cross-provider
  fallback.
- **Protocol and limitations:** Live model and inference-profile discovery plus
  Bedrock Runtime invocation. Availability, streaming, tools, and reasoning
  vary by model and region.
- **Unlimited use:** RouteKit makes no unlimited-use claim.

<a id="route-openrouter-api"></a>

## OpenRouter API

- **Status and evidence:** Current qualification: pending. The RouteKit 0.8.0 /
  2026-07-22 durable report records deterministic Chat Completions and dynamic
  reasoning-capability passes while required live outcomes remain pending.
  [Evidence](https://github.com/velum-labs/routekit/blob/main/docs/routekit-l06-evidence.md#route-openrouter-api).
- **Credential:** User-owned `OPENROUTER_API_KEY`.
- **Billing:** OpenRouter API-key/credit route; OpenRouter determines charges.
- **Egress and aggregator:** **OpenRouter is an aggregator.** RouteKit sends
  prompts, code, tool data, and model requests to `openrouter.ai`, which
  forwards them to an upstream provider under OpenRouter routing.
- **Quota and failover:** No RouteKit account pool or silent direct-provider
  switch.
- **Protocol and limitations:** OpenAI Chat Completions; tools and streaming
  depend on OpenRouter and the upstream model.
- **Unlimited use:** RouteKit makes no unlimited-use claim.

<a id="route-codex-subscription"></a>

## Codex subscription

- **Status and evidence:** Current qualification: pending. The RouteKit 0.8.0 /
  2026-07-22 durable report records a deterministic Responses pass; live
  account, client, billing, and setup/restore outcomes remain pending.
  [Evidence](https://github.com/velum-labs/routekit/blob/main/docs/routekit-l06-evidence.md#route-codex-subscription).
- **Credential:** User-owned Codex OAuth credential from
  `accounts login codex`.
- **Billing:** Subscription plan usage determined by the provider.
- **Egress and aggregator:** Relays to `chatgpt.com/backend-api/codex` with the
  enrolled OAuth credential; never `OPENAI_API_KEY`. No third-party aggregator.
- **Quota and failover:** Rotates eligible Codex accounts only. Before response
  output is committed, credential-scoped authentication failures can trigger
  coalesced refresh and reroute to a healthy account in the same pool.
  Exhaustion never invokes a paid OpenAI API-key route.
- **Protocol and limitations:** OpenAI Responses with streaming and tools.
- **Unlimited use:** RouteKit makes no unlimited-use claim.

<a id="route-claude-code-subscription"></a>

## Claude Code subscription

- **Status and evidence:** Current qualification: pending. The RouteKit 0.8.0 /
  2026-07-22 durable report records deterministic Messages and thinking passes;
  live account, client, billing, and setup/restore outcomes remain pending.
  [Evidence](https://github.com/velum-labs/routekit/blob/main/docs/routekit-l06-evidence.md#route-claude-code-subscription).
- **Credential:** User-owned Claude Code OAuth credential from
  `accounts login claude-code`.
- **Billing:** Subscription plan usage determined by Anthropic.
- **Egress and aggregator:** Relays to Anthropic with the enrolled OAuth
  credential; never `ANTHROPIC_API_KEY`. No third-party aggregator.
- **Quota and failover:** Same-kind eligible-account rotation. Before response
  output is committed, credential-scoped authentication failures can trigger
  coalesced refresh and reroute within that pool. Exhaustion never invokes a
  paid Anthropic API-key route.
- **Protocol and limitations:** Native Anthropic Messages relay with streaming
  and tools.
- **Unlimited use:** RouteKit makes no unlimited-use claim.

<a id="route-cursor-ide"></a>

## Cursor custom OpenAI endpoint

- **Status and evidence:** Current qualification: pending. Cursor's manual
  custom-endpoint walkthrough and required protocol, billing, failure, and
  setup outcomes remain pending in the RouteKit 0.8.0 / 2026-07-22 durable
  report.
  [Evidence](https://github.com/velum-labs/routekit/blob/main/docs/routekit-l06-evidence.md#route-cursor-ide).
- **Credential:** Logged-in Cursor account plus a local gateway token; model
  egress uses the selected RouteKit route credential.
- **Billing:** Custom-endpoint model calls use the selected RouteKit route's
  billing mode; Cursor-owned services remain separate.
- **Egress and aggregator:** Model calls go through the selected RouteKit route.
  Composer, autocomplete, and other Cursor-owned features can contact Cursor
  cloud.
- **Quota and failover:** Adds no fallback; the selected provider route's rules
  apply.
- **Protocol and limitations:** Custom OpenAI endpoint for Agent chat/plan. The
  `cursor-agent` CLI is not covered.
- **Unlimited use:** RouteKit makes no unlimited-use claim.
