RouteKit is an open-source CLI and authenticated model gateway for coding
tools. Connect API providers or enroll Codex and Claude Code subscriptions,
then use the discovered models through one stable local endpoint.

## The basic workflow

1. **Connect a route.** Add an API provider or enroll a Codex or Claude Code
   subscription account.
2. **Discover available routes.** RouteKit builds a catalog from the models
   available to your credentials.
3. **Use a qualified workflow.** Launch a coding tool and choose from its native
   model picker, or call the authenticated HTTP gateway with an exact model ID.
4. **See what happened.** Inspect health, account activity, usage, and call
   attribution from the CLI.

For interactive coding sessions, the native picker is the simplest way to
choose and switch models. Exact IDs such as `codex/<model>` or
`anthropic/<model>` are still important for HTTP requests, automation, and
reproducible startup. Each ID stays attached to its provider and billing path.
RouteKit does not silently move a request to a different provider or from a
subscription to a paid API route.
