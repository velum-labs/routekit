tools. Connect API providers or enroll Codex and Claude Code subscriptions,
then use the discovered models through one stable local endpoint.

## The basic workflow

1. **Connect a route.** Add an API provider or enroll a Codex or Claude Code
   subscription account.
2. **Choose a model.** RouteKit discovers the models available to your
   credentials and lists their exact namespaced IDs.
3. **Use it in a qualified workflow.** Launch a coding tool through RouteKit or call
   the authenticated HTTP gateway.
4. **See what happened.** Inspect health, account activity, usage, and call
   attribution from the CLI.

A model ID such as `codex/<model>` or `anthropic/<model>` stays attached to that
provider and billing path. RouteKit does not silently move a request to a
different provider or from a subscription to a paid API route.
