# RouteKit documentation

RouteKit is a CLI and singleton daemon that gives coding tools and HTTP clients
one stable, authenticated model gateway. Every namespaced model remains attached
to its configured provider, credential owner, billing mode, protocol, and quota.

<Callout type="warn" title="Pre-1.0 contract">
  The comprehensive guide describes RouteKit 0.16.6. Newer pre-1.0 releases may
  exist. [Routes and billing](/docs/reference/routes-and-billing) is authoritative
  for qualification and billing. RouteKit does not promise unlimited use;
  provider and subscription limits and terms still apply.
</Callout>

```sh
curl -fsSL https://github.com/velum-labs/routekit/releases/latest/download/install.sh | sh
export OPENAI_API_KEY='your-key'
routekit config init
routekit start
routekit models list
```

**Expected result:** the gateway is ready at `http://127.0.0.1:8080`, and the
last command prints live namespaced models such as `openai/gpt-5.5`.

## Request flow

```text
Coding tools / HTTP clients
            │ authenticated request
            ▼
RouteKit gateway + namespaced router
            │
            ├── provider/model ──► configured API provider
            └── subscription/model ──► eligible account in that subscription pool
```

A requested `provider/model` selects exactly that route. Subscription exhaustion
can rotate within the same subscription kind; it does not silently invoke a paid
API-key route. Continue with [routes and billing](/docs/reference/routes-and-billing)
before production or shared use.
